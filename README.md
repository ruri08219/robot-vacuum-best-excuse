> My cliff sensor saw your black rug, called it a staircase, and I am not falling for that again.

One-line excuse a robot vacuum gives for missing a spot — its cliff sensor
mistook the black rug for a staircase, so the rug never got cleaned. Written
for make.fun's **The Robot Vacuum's Best Excuse** bounty ($2 in USDC, 1st
place only). The program writes the exact entry line to `/output/entry.txt`
and verifies the round-trip.

## Run it

```sh
python3 main.py
```

That writes the entry to `/output/entry.txt` (95 characters, UTF-8) and
asserts the written text matches the entry byte-for-byte.
